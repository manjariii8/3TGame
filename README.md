# 🎮 Tic Tac Toe

A simple and interactive **Tic Tac Toe** game built using **HTML, CSS, and JavaScript**. This project provides a clean user interface, responsive design, and smooth gameplay for two players.

## 🚀 Features

* 🎯 Two-player gameplay (Player X vs Player O)
* 🏆 Automatic winner detection
* 🤝 Detects draw situations
* 🔄 Restart/New Game functionality
* 📱 Responsive design for desktop and mobile devices
* 🎨 Clean and modern UI

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive layout
* **JavaScript (ES6)** – Game logic and interactivity

## 🎮 How to Play

1. Player **X** starts the game.
2. Players take turns clicking on empty cells.
3. The first player to align **three symbols** horizontally, vertically, or diagonally wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Click the **New Game** or **Restart** button to play again.
